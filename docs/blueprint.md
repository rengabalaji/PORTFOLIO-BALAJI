# **App Name**: MotionVerse Portfolio

## Core Features:

- Hero & About Page: Display an engaging hero section with animated 3D icons, interactive particle background (Particles.js), animated gradient blurs and the the user's introduction, profession, achievements.
- Call to Action Page: Animate a prominent 'Contact' button with glowing effects and subtle motion blur on hover to encourage user interaction.
- Projects Showcase: Showcase past projects in a visually appealing grid or carousel layout, with 3D hover animations using Three.js for enhanced interactivity and lazy loading to improve initial performance.
- Skills Presentation: Visualize the user's skills using animated icons with dynamic counters or progress bars, displaying proficiency levels with Framer Motion animations.
- Interactive Contact Form: Implement a user-friendly email form with real-time validation to ensure correct data input and animated success message upon submission.
- Coding Profiles: Showcase links to the user's coding profiles (e.g., LeetCode, GitHub) in a stylish card format, featuring smooth pop-in animations.
- Social Links: Animate social media icons (LinkedIn, Instagram, GitHub) on hover to make the site more interactive.

## Style Guidelines:

- Background color: Dark charcoal gray (#121212) for a modern, immersive feel.
- Primary color: Electric purple (#BE29EC) to create an intense futuristic atmosphere.
- Accent color: Vivid blue (#2980EC) for highlighting interactive elements and drawing attention.
- Body and headline font: 'Space Grotesk' for headlines and short chunks of text, and 'Inter' for body text, offering a blend of modernity and readability.
- Use glowing icons to complement the neon color scheme, and reinforce the cyber feeling.
- Employ full-page layouts with seamless transitions to provide a cinematic user experience.
- Incorporate animated gradient blur backgrounds and particle effects to create a visually dynamic environment.
